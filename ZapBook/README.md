# Projecto simples: ZapBook

## Introdução
Este e um simples projecto de cadastro de usuarios com **Cookies e authetificacao **
ele serve simplesmente para melhorar a pratica do **flask: backend** e **HTML+CSS: frontend**
e banco de dados com __SQLAlchemy: mysql__ 

## Arquivos e Pastas
1. `app.py`: arquivo principal com a rotas
1. `config.py`: arquivo com as configuracoes principais do projecto com _3 classes_
1. `forma.py`: arquivo com a configuracao do formulario com __wforms e flask-forms__ 
1. `models.py`: arquico com os `modelos , ORMS ou tabelas` do banco de dados com __sqlalchemy__
1. `requirements.txt`: arquivo com as bibliotecas necessarias a fazer download
1. static/ arquivos CSS
1. templates/ arquivos HTML
1. repo/ base de dados (sem autorisacao de visualisacao)

## Como usar o projecto
1. clonar o repositorio com: `bash: git clone https://github.com/TecnicoManuel2008/ZapBook.git`
1. instalar o python no dispositivo ou maquina
1. criar ambiente virtual
1. baixar os recursos(_libs_) do projecto com: `bash: python install -r requirements.txt`
1. iniciar o projecto: `bash: python app.py`
